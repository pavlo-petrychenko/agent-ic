# WidgetPreview
Purpose: "Live preview" stage showing the customer web widget: panel plus launcher; accent follows widget setting.
Anatomy: stage (card `--color-soft`, border `--color-line`, `--radius-12`, h400, label "Live preview" overline) ; panel 300 wide radius 16, bg `--color-card`, shadow `--shadow-popover` (light 0 10px 28px rgba(31,29,26,.14), dark 0 12px 32px rgba(0,0,0,.55); drawn on DS-Flow-Chat and DS-Dark-Flow-Chat); header (widget accent bg, text #FFFFFF literal, avatar 32 circle #FFFFFF with initials in the widget accent, name 600, subtitle 11.5px opacity .8); body (bg `--color-bg`, pad 14, gap 8, bubbles 12.5px max 230); input row (top border `--color-line`, placeholder 12px `--color-mute`).
Bubbles: bot left (`--color-card`, border `--color-line`, 14/14/14/4); user right (widget accent bg, #FFFFFF literal text, 14/14/4/14).
Props (decided): `{ stageLabel: string; name: string; subtitle: string | null; initials: string; accent: string; messages: {from:'bot'|'user', text}[]; typingLabel: string | null; open: boolean; onToggle: () => void; openLabel: string; closeLabel: string; composerPlaceholder: string; composerLabel: string; sendLabel: string }`. The stage is 400 high with the launcher at right 24, bottom 24 and the panel (a non-modal `dialog`, 300 wide) 12 above it; the body scrolls and sticks to the newest message. The composer is a live WidgetComposer whose draft clears on send. `typingLabel` shows a TypingIndicator in its widget view after the messages. The prop notes follow: accent is the customer's widget colour setting (default teal #0F6B6B); it is not the product accent, and blue/violet design-tool options have no kept values.
Tokens: `--radius-16`, `--radius-14`, `--radius-12`, `--color-card`, `--color-bg`, `--color-line`, `--color-mute`, `--shadow-popover`. Accent comes from runtime colour (`--widget-accent`), not tokens; text on the widget accent is literal #FFFFFF in both themes (NOT `--color-on-accent`, which turns #0B1F1D in dark).
A11y: widget real: role=dialog, input labelled, Esc closes, focus to input on open.
Light/dark (drawn on DS-Dark-Flow-Chat): stage `--color-soft` (#2A2824) / `--color-line` (#34312C). The preview panel follows the dashboard theme: panel `--color-card` #211F1C, body `--color-bg` #151412, bot bubble #211F1C + #34312C border, input row border #34312C and placeholder `--color-mute` #A29C92. Header, user bubble and launcher keep the customer accent with #FFFFFF text. Decided: the widget dark theme follows the dashboard tokens, in the preview and on the customer site. Responsive: below 1280px the wizard preview becomes a drawer over the content (opened by a Preview button in the wizard footer); below 1024px the app shows "Open on a wider screen". Widget composer: drawn on DS-Patterns > Chat extras as a vision item ("not in MVP"), see WidgetComposer: attach IconButton + borderless input 34 + accent send IconButton 28. Typing indicator: see TypingIndicator. The widget's own states (loading, error, offline, hover/focus on the input): still UNDESIGNED. DS-Dark-Patterns draws the widget header text, the avatar fill and the send icon in `--color-on-accent` (#0B1F1D) on the accent. Decided: text on a customer accent is #FFFFFF; `--color-on-accent` is used only when the widget uses the product accent. Focus on the real input uses the field rule (1px accent border + 3px soft halo).
Used: DS-Flow-Chat; DS-Patterns (widget with composer). Composer: see WidgetComposer.
