# FlowNode
Purpose: full flow-builder node card (agent, guard, send message, API, etc.) with header, optional meta, chips and output line.
Anatomy: card; NodeHeader (kind icon tile + overline kind + name); optional NodeMeta; optional chip row (Tag); optional NodeOutput; optional Callout. Widths 248 (full) or 200 (decision, single-row 48px). Pad 12x14, gap 8, radius 12.
Variants: kind (agent, guard/completion, send_message, api_request, decision(condition), parallel, ...). Sizes: full(248), condition(200, h48, header only).
States: default (border 1px, shadow-node); selected (designer: 2px accent border + 4px halo, `--shadow-selected`; padding reduced by 1 to avoid layout shift; decided: FlowNode keeps border + halo, TriggerNode keeps its gap ring). Selection is not focus. focus-visible (keyboard): outside ring with 2px gap (`--shadow-focus-ring`), distinct from the selected halo; a node can be both. disabled: normal colours at 45%, no hover/focus, not-allowed. hover (decided): border `--color-edge`. error/invalid node (decided): border `--color-err` and an `alert` icon in the header. Ports/handles: drawn on DS-Patterns (see FlowPort): one in-port top centre and one out-port bottom centre, hidden until the node is hovered or selected; a router has one out-port per route plus else, in rule order; while an edge is being drawn, nodes that cannot accept it fade to 40% opacity. The DS-Patterns boards draw nodes at 220 wide (selected 170) and 56–62 high with a 22 tile (radius 6, icon 13), overline 10.5/600 .04em in the hue colour, name 13/600: the same anatomy at a smaller board size (widths stay 248 / 200).
Props: `{ kind: NodeKind; name: string; meta: string | null; chips: TagItem[]; output: string | null; callout: {tone, text} | null; selected: boolean }`, NodeKind enum.
Tokens: bg `--color-card`; border `--color-line-node` 1px (`--border-width`); selected border `--color-accent` (--border-width-strong), halo `--shadow-selected` (4px accent soft); shadow `--shadow-node`; radius `--radius-12`; pad `--space-12`/`--space-14`; gap `--space-8`; text `--type-title`, `--color-ink`.
A11y: role=button or option within canvas, aria-selected / aria-pressed, Enter selects, Delete removes; ports must be reachable. No Radix.
Light/dark: node bg uses --color-card, tiles use the 18 hue pairs; all have dark values (tokens.md); --shadow-node is a per-theme token.
Used: DS-Flow-Chat. Existing code: none (Card is closest, `--radius-12`).
